# UI 规格基线

## 1. 视觉基准与未决输入

用户提供的 UI 参考图是像素级视觉最高依据。目前项目目录未包含参考图；在拿到图片之前，颜色、尺寸、字体权重、间距、边框、圆角及确切布局标记为未冻结，不以文字描述自行替代图片。需求文本描述“清爽、明亮、易读”，架构文字描述“深色工作台”，存在冲突；最终以参考图为准。

## 2. 页面结构

```text
App
├─ 自定义标题栏（无边框 pywebview）
├─ 左侧导航：任务工作台 / 下载历史 / URL规则 / 偏好设置
└─ 主工作区
   ├─ 下载模式（直接 URL / 规则）
   ├─ 输入及规则配置/预览
   ├─ 保存位置（根目录、可选子目录）
   ├─ 总体状态与进度
   └─ 下载队列及近期日志入口
```

直接模式明确显示“一行一个 HTTP/HTTPS URL”；规则模式明确显示规则、基础 URL、名称/版本输入格式及预览。设置、历史、规则管理和日志需可从导航访问。

## 3. 工作台行为

- 输入校验结果按行展示；无效行不阻断有效项创建。
- 队列行呈现文件名、状态、进度、错误摘要及适用操作；状态至少区分等待、下载中、完成、失败、取消、等待用户。
- 提供停止、单项重试、重试失败项；冲突等待用户时展示覆盖/重命名/跳过操作。
- 清楚显示当前输出位置、并发设置、模式与总体下载情况。总体进度算法待参考图/产品确认。
- 支持查看近期事件日志和导出。

## 4. 桌面与可访问性

- pywebview 无边框窗口；标题栏提供最小化、最大化/还原、关闭、拖动。Native Bridge 提供 Windows 原生文件夹选择及打开目录。
- 中文字体回退：`Microsoft YaHei UI`、`Microsoft YaHei`、`Segoe UI`、`sans-serif`。
- 常用状态应通过文字标签识别，不只依赖颜色；错误说明应面向用户。
- 目标视口：1024×768、1124×1068（参考图尺寸）、1366×768、1440×900、1920×1080。DPI：100%、125%、150%。
- 不裁切、重叠、文字溢出、表格不可用或中文乱码。

## 5. 视觉验收方法

取得参考图后固定基准图片及视口/DPI，在 Playwright 截图对比中保存 `reference.png`、`current.png`、`diff.png`。除非用户要求，不擅自改变已确认视觉。DEV-03 开始前需将原图放入可追踪的项目位置并确认目标页面/视口。
