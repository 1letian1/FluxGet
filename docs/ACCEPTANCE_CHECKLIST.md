# 发布验收清单

状态使用：`未验证`、`通过`、`失败`、`阻塞`。新项目全部默认为未验证。证据（测试名、截图、环境）应在执行阶段补充；不得仅凭代码生成勾选通过。

## 产品功能

- [ ] 单 URL 下载成功
- [ ] 多行 URL 忽略空行；错误行清晰提示且有效行可加入
- [ ] HPI 内置规则与旧输入行为经样例确认
- [ ] 自定义规则新增、查看、编辑、删除并持久化
- [ ] 预览与实际任务 URL/文件名完全一致
- [ ] 输出根目录与子目录可配置且显示清楚
- [ ] 队列显示任务名、状态、进度、错误及总体进度
- [ ] 单任务取消、失败任务单项/批量重试
- [ ] 并发默认 4 且可设 1–32
- [ ] Range 206 可续传；忽略 Range 时从头重下并提示
- [ ] `.part` 写入并在完成后原子替换目标文件
- [ ] 用户取消不自动重试且保留部分文件
- [ ] 超时/连接错误/指定 5xx 按上限和退避重试；普通 4xx 不重试
- [ ] 覆盖、重命名、跳过、询问冲突流程正确；询问不占并发槽
- [ ] 输出路径阻止穿越并处理 Windows 保留名
- [ ] 设置及规则重启后保留
- [ ] 异常重启恢复下载任务及 `.part`
- [ ] 历史正确；清除完成队列不误删历史或文件
- [ ] 近期日志可查看并可导出

## 界面与桌面

- [ ] UI 按确认的参考图 1:1 验收
- [ ] 1024×768、1124×1068、1366×768、1440×900、1920×1080 无裁切/重叠
- [ ] DPI 100%、125%、150% 下可用
- [ ] 中文显示正常，状态不只依靠颜色表达
- [ ] 原生文件夹选择、打开目录、窗口控制与拖动正常
- [ ] 安全关闭等待后台工作，不留下访问已销毁界面的线程

## 安全、兼容与交付

- [ ] API 只监听 127.0.0.1 随机端口
- [ ] Session Token 验证正常；不开放任意 CORS/局域网访问
- [ ] 单 EXE 在无 Python/Node/npm 的 Windows 环境运行
- [ ] Portable 目录版在无 Python/Node/npm 的 Windows 环境运行
- [ ] Win10 验收
- [ ] Win11 验收
