URL Downloader - Portable

Run URLDownloader.exe from this folder. Keep the complete folder together;
the _internal directory contains the application runtime and bundled frontend.

The application stores settings, downloads history, and logs in your Windows
Local AppData folder under UniversalDownloader. This existing data-folder name
is retained so upgrades preserve settings and download history. Removing this
portable folder does not remove that user data.

This package does not install Python, Node.js, or npm. The Windows WebView2
runtime must be available for the desktop window.
